## 2026-09-17：重复请求取消隔离

- AIClient 的重复请求直接等待共享 Future，单个等待者取消会污染其他等待者；原请求被取消时又没有结算共享 Future，可能留下永久等待。
- 等待者使用 asyncio.shield 隔离取消；原请求取消时显式取消共享 Future 并继续传播取消。保留现有去重与重试策略，不引入后台请求。
- 两条并发回归测试修复前均失败，修复后 AIClient、AgentRuntime、优化与可观测性共 117 项通过（5.00 秒）。使用模拟 HTTP，不调用付费 API 或发送微信消息；不据此声称线上不回复已恢复。
