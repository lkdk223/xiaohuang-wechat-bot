# v1.7.0 更新内容

## Features

- 新增微信 4.x 可见界面自动化传输后端，支持精确白名单私聊与群聊的纯文本回复。
- 白名单支持同时监听多个会话；群聊继续受 @ 与回复策略控制，并保持红包、转账、支付和媒体消息禁用。
- OpenAI / Codex 本机认证回复链路支持可选联网搜索。

## Improvements

- 改进微信 4.x 独立聊天窗口的重连、复用和多联系人精确路由。
- 新增 Windows 安装包与便携版的微信 4.x 自动化依赖收集和第三方开源许可说明。

## Fixes

- 修复微信将独立聊天窗口标题暴露为 `Weixin` 时无法重新接管监听的问题。
- 修复打包后未显式收集 `pyweixin` 动态传输模块和共享模型目录的问题。
